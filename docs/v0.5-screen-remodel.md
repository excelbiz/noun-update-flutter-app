# 0.5.0 screen structure preview

This build changes the main screen layout. It is not the feature-complete Release 1.

Implemented:
- Home / Study / Tools / Updates / Profile bottom navigation.
- Separate header-accessible notification inbox, unread-only filter and existing read tracking.
- Home greeting, student details, next-step card, examination availability, study entry, wallet entry, courses and updates.
- Optional editable student details stored per signed-in account on the device (guest separate).
- Add/remove saved course codes and open course hubs. Libraries still require searching the course code; classifications are explicitly unverified.
- Tools grouped by directory category with persistent pin/unpin actions and search.
- Updates filters for news, guides, scholarships and careers.
- Profile groups for student details, courses, account/wallet, library/membership, preferences, security and support.
- Existing fonts, automatic theme, accents and text sizes retained.

Still unavailable: cross-device student/course sync, central-wallet funding/purchases, personal examination data, download manager, saved-resource manager, premium entitlement screens, verified PAS matching and restored reading progress. Entries for these state their availability honestly. Do not advertise this build as completion of the Release 1 brief.

Screenshots are rendered widget tests using sample data. APK uses the configured website APIs, whose live deployment remains outstanding. APK signing is for preview installation, not Play Store distribution.
