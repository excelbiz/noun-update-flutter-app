# v0.7 reference-art skin update

Extends the existing app. The free default theme, server entitlements,
wallet, authentication, API contracts and navigation remain in place.

Changes:
- Shared decorative campus/study backgrounds and independent light/dark overlays.
- Campus photography-style headers, gold light, academic book imagery and friendly student artwork.
- Skin-specific list/grid resource presentation, coloured semantic cards, glass surfaces,
  editorial typography, rounded friendly cards and restrained emerald light paths.
- Gallery previews use the actual LivePortal and NativeAuth widgets with an isolated
  read-only API fixture. Sample quotes never overwrite the live daily quote cache.
- Gallery supports all five app tabs, sign-in and independent appearance preview.
- Premium resource grids reserve height for enlarged text on narrow phones.

Artwork is illustrative, not a photograph of an identified NOUN campus. The three
WebP assets total 155,972 bytes. They load on demand, use bounded decode sizes and
reuse Flutter's image cache. There are no animated backgrounds or additional image
network requests. The official user-supplied /images/logo.webp branding remains.

Assets in assets/images/skins/ were generated using built-in image generation:
- campus.webp: portrait Nigerian university-style campus at dusk, deep emerald,
  gold sunset and subtle burgundy/gold ribbon; quiet central space; no text/UI.
- students.webp: warm mature 3D editorial illustration of two Black university
  students studying, green/cream clothes, laptop/books, space at left; no text/UI.
- study.webp: open textbook, green/burgundy/gold books and laptop on the right,
  emerald/gold lighting with quiet left space; no text/UI.
Reference posters supplied by the user guided the artwork and treatments.
Generated originals were encoded at 768/960 px to keep the APK lightweight.

Limits: this is a reference-inspired implementation, not a pixel-identical tracing
of the posters. Those posters show differing data, navigation and promotional
layouts; the actual app retains the requested common navigation and honest data.
No pending educational API, checkout activation or analytics feature is claimed
complete by this visual update. No production server deployment occurred.

Validation: existing default-screen/API tests plus real-screen skin snapshots,
preview entitlement isolation, no quote-cache pollution, and 320 px / 1.5x text
study navigation. Final CI result accompanies the APK delivery.
